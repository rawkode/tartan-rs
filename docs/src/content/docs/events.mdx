Each actor appends an event to its own log in the same transaction as the change it records.

```json
{
  "id": "01kx…",
  "source": "repo:01kx…",
  "seq": 7,
  "type": "ref.updated",
  "at_ms": 1789000000000,
  "data": { "ref_name": "refs/heads/main", "old": "…", "new": "…" }
}
```

`source` names the log (`forge`, `org:<id>`, `repo:<id>`, `extension:<id>`) and `seq` is the event's position in it. `(source, seq)` identifies an event.

## Subscribers

```sh
curl -X PUT -H "Authorization: Bearer $TOKEN" localhost:8080/-/api/subscribers/audit \
  -d '{"pattern": ">"}'
curl -H "Authorization: Bearer $TOKEN" "localhost:8080/-/api/subscribers/audit/events?after=0"
```

A pattern is dot-separated tokens: `*` matches one token and a final `>` matches one or more. `repo.*` matches `repo.ready`; `ref.>` matches `ref.updated`; `>` matches everything.

Each source delivers matching events in order and retries until the subscriber has stored them, so delivery is at least once and the subscriber stores each `(source, seq)` once. A new subscriber receives the history it matches.

## Event types

| Type | Source | When |
| --- | --- | --- |
| `org.created` | forge | an org is created |
| `org.ready` | org | the org actor is set up |
| `repo.created` | org | a repository is created |
| `repo.ready` | repo | the repository exists on the Git host |
| `push.accepted` | repo | walgit committed a push |
| `ref.updated` | repo | a ref changed in a push |
| `placement.set` | forge | a placement changed |
| `subscriber.registered` | forge | a subscriber was added or changed |
| `package.published` | forge | an extension package was published |
| `extension.subscribed` | forge | an installation's subscriptions changed |
| `config.applied`, `config.refused` | org or repo | a `tartan.cue` was applied or refused (see [Configuration](/configuration/)) |
| `extension.installed`, `.upgraded`, `.configured`, `.uninstalled` | org or repo | configuration changed an installation |
| `x.<extension>.<type>` | extension | an extension emitted an event |
